# 💬 FriendChat

**FriendChat** is a modern real-time messaging web application designed for fast, private, and seamless communication. Users can chat with friends individually or in groups, share media, send voice notes, and personalize their profiles.

### ✨ Features

* 🔐 User authentication & secure login
* 💬 Real-time one-to-one messaging
* 👥 Group chats
* 🖼️ Photo & video sharing
* 🎤 Voice messages
* 📞 Voice & video calling
* 👤 Custom profile pictures
* 🟢 Real-time online messaging
* 📱 Responsive design for mobile and desktop
* ⚡ Powered by Supabase for real-time backend functionality

### 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Supabase
* **Database:** PostgreSQL
* **Realtime:** Supabase Realtime
* **Authentication:** Supabase Auth
* **Storage:** Supabase Storage

### 🚀 Goal

The goal of FriendChat is to create a simple, modern, and feature-rich communication platform that feels fast and familiar while giving users essential messaging and social features in one place.
